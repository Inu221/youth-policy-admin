### 4. 📈 Автообновление счетчика участия

**Описание:** ТЗ требовало автоматически обновляемое поле `attendance_count`.

**Реализация:**
- ✅ **Файлы:**
  - `app/Observers/ActualEventParticipantObserver.php` - observer для pivot таблицы
  - `app/Console/Commands/RecalculateParticipantAttendance.php` - команда для пересчета
  - Зарегистрировано в `app/Providers/AppServiceProvider.php`

- ✅ **Функционал:**
  - При добавлении участника к мероприятию → `attendance_count++`
  - При удалении участника из мероприятия → `attendance_count--`
  - Автоматическое обновление в реальном времени
  - Команда для пересчета всех счетчиков: `php artisan participants:recalculate-attendance`

**Как работает:** Используется модель `ActualEventParticipant` с Observer. При событиях `created`/`deleted` автоматически пересчитывается количество участий.
